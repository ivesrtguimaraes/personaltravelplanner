Como atualizar sem perder a configuração da nuvem
1. Exporte um backup dentro do app antes de atualizar.
2. Envie os arquivos deste pacote para o MESMO repositório do GitHub, substituindo os arquivos de mesmo nome.
3. Preserve o arquivo src/cloud-config.js que já está no seu repositório. Este pacote não precisa substituir esse arquivo.
4. Faça o commit e aguarde a publicação no GitHub Pages.
5. Reabra o app no computador e no iPhone. Se o iPhone ainda mostrar a versão antiga, feche o app instalado e abra novamente.
